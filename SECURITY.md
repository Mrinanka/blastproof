# Security Policy

The security of Blastproof and the safety of the systems it protects are of paramount importance. We appreciate the responsible disclosure of any vulnerability found in this project.

---

## Supported Versions

Only the latest release and the current `develop` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report vulnerabilities by one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Submit an advisory via the [Security Advisory page](https://github.com/Mrinanka/blastproof/security/advisories/new) if available.
2. **Email**: Send an encrypted or plain email to **mrinanka.dhar@gmail.com** with the subject line `[SECURITY] Blastproof Vulnerability Report`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal proof-of-concept (PoC) to reproduce the issue.
- The environment and version where the vulnerability was observed (OS, Python version, Blastproof version/commit).
- Any proposed remediation or patch, if available.

### What to Expect

- **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
- **Assessment**: We will investigate the issue, determine its severity, and keep you informed of our progress.
- **Coordination**: We will coordinate with you on the timeline for publishing a fix and releasing a public advisory with proper credit/attribution.

Thank you for helping keep Blastproof and AI agent systems secure!
